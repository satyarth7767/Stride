## About

Stride combines focused study sessions, screen-time awareness, analytics, goals, journaling and productivity tools in one Android app.

## Highlights

- ⏱️ Focus timer and Zen mode
- 📱 On-device screen-time tracking
- 📊 Study analytics and progress charts
- 📚 Subjects, goals and syllabus tracking
- 📝 Study journal and reflections
- 🎵 Focus music and ambient sounds
- 🤖 Study guidance
- 🔄 In-app update support
- 📴 Local-first data storage

## Technology

- Kotlin
- Jetpack Compose
- Material 3
- Room
- Android UsageStatsManager
- Gradle

## Privacy

Stride V2 is designed to operate locally on the device without requiring a user account or cloud database.

Never commit API keys, signing credentials or `.env` files.
