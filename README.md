## ✦ What is Stride?

**Stride** is a focused study and productivity app designed around one simple idea:

> **Consistent progress beats occasional intensity.**

It brings focused study sessions, screen-time awareness, analytics, goals, journaling, music and productivity tools into a single, distraction-conscious experience.

Stride V2 is designed as a **local-first Android app**. There is no account required to get started, and core productivity data is stored on the device.

---

## 🚀 Features

| Feature | What it does |
|---|---|
| ⏱️ **Focus Timer** | Pomodoro, stopwatch and dedicated focus sessions |
| 🧘 **Zen Mode** | A distraction-resistant environment for deep work |
| 📱 **Screen Time** | On-device app usage tracking and category breakdowns |
| 📊 **Analytics** | Study trends, history, streaks and visual progress |
| 📚 **Subjects & Goals** | Organize study targets and track milestones |
| 📝 **Journal** | Record study notes, reflections and progress |
| 🎵 **Focus Sounds** | Lo-fi, ambient and study-friendly audio |
| 🔄 **In-App Updates** | Built-in update flow for future releases |

## 🎨 Design

Stride uses a dark, futuristic visual language with vibrant accents, clean Material 3 components and a focus on clarity over clutter.

**Design principles:**

- Minimal distraction
- Fast navigation
- Clear information hierarchy
- Strong visual feedback
- Consistent spacing and typography
- Modern, energetic color accents

---

## 🧠 The Stride Loop

```text
        START
          ↓
        FOCUS
          ↓
        TRACK
          ↓
        REVIEW
          ↓
        IMPROVE
          ↓
        REPEAT
```

The purpose is not to make users stare at a timer all day. It is to create a simple feedback loop that helps them understand their habits and improve them over time.

## 🔐 Privacy & Security

Stride V2 is designed to work without requiring a user account or cloud database for its core functionality.

Sensitive values should never be committed to the repository.

Do not commit:

```text
.env
google-services.json
*.jks
*.keystore
API keys
```

## ⚙️ Getting Started

### 1. Clone

```bash
git clone https://github.com/satyarth7767/Stride.git
cd Stride
```

### 2. Open

Open the project in **Android Studio** and let Gradle finish syncing.

### 3. Build

Connect an Android device or start an emulator, then run the `app` configuration.

> Some device features, including screen-time tracking, require Android's relevant system permissions.
